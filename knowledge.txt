Python was created by Guido van Rossum and first released in 
1991.
FastAPI is a modern Python web framework used for building 
APIs.
It is built on top of Starlette and Pydantic.
LangChain is a framework for developing applications powered 
by language models.
It provides components for prompts, document loading, 
retrieval, and agents.
RAG stands for Retrieval-Augmented Generation.
A RAG system retrieves relevant information from a knowledge 
base
and provides that information to an LLM to generate an 
answer.
